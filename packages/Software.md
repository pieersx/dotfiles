## 🛠️ Utilidades del Sistema
- **[APP Center (Gigabyte)](https://www.gigabyte.com/latam/Motherboard/B550M-DS3H-rev-10-11-12-13/support#support-dl)** — Driver para placas base Gigabyte.
- **[Nvidia App](https://www.nvidia.com/es-la/software/nvidia-app/)** — Aplicación oficial para administrar controladores y configurar tu tarjeta gráfica NVIDIA.
- **[PowerToys](https://github.com/microsoft/PowerToys)** — Conjunto de utilidades para usuarios avanzados.
- **[Advanced SystemCare](https://www.iobit.com/es/advancedsystemcarepro.php)** — Optimización y limpieza del sistema.
- **[Revo Uninstaller](https://www.revouninstaller.com/)** — Desinstalación avanzada de programas.
- **[Fastfetch](https://github.com/fastfetch-cli/fastfetch)** — Información del sistema (inspirado en Neofetch).
- **[TranslucentTB](https://github.com/TranslucentTB/TranslucentTB)** — Hace la barra de tareas translúcida.
- **[Lively Wallpaper](https://www.rocksdanister.com/lively/)** — Fondos de pantalla animados.
- **[UniGetUI](https://github.com/marticliment/UniGetUI)** — Interfaz para instalar y gestionar paquetes con winget, Chocolatey y Scoop.

## 📦 Gestores de Paquetes y Shell
- **[PowerShell 7](https://github.com/PowerShell/PowerShell)** — Shell avanzada para automatización.
- **[Git](https://git-scm.com/)** — Control de versiones.
- **[Fzf](https://github.com/junegunn/fzf)** — Fuzzy Finder para terminal.
- **[Starship](https://starship.rs/)** — Prompt minimalista y rápido para cualquier shell.

- **[Terminal Icons](https://github.com/devblackops/Terminal-Icons)** — Íconos para archivos y carpetas en PowerShell.
- **[CompletionPredictor](https://github.com/PowerShell/CompletionPredictor)** — Predicción de comandos.
